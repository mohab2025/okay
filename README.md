# Okay — idea to intelligent product

Arabic-first, bilingual Next.js website for product development, AI agents,
business automation, and project partnerships. Official domain: https://okai.sa.

## Run

```sh
npm install
npm run dev
npm run lint
npm run build
npm run start -- -p 3001
```

Open /ar for Arabic RTL or /en for English LTR. The default locale is Arabic;
explicit locale URLs and the language switcher preserve both experiences.

On this Windows installation the npm launcher is broken. Equivalent commands:

```powershell
node node_modules/eslint/bin/eslint.js .
$env:SWC_NATIVE_BINDING_CACHE="$env:USERPROFILE\.swc"
node node_modules/next/dist/bin/next build
node node_modules/next/dist/bin/next start -p 3001
```

The SWC cache must be accessible to the current user. Do not change filesystem
permissions or disable validation to work around a restricted execution sandbox.

## Project organization

- src/app: localized routes, metadata, sitemap, robots, social preview.
- src/components/home/landing: server homepage composition and hero/developer demos.
- src/components/home/narrative: journey, connected workflow, industry preview,
  growth, governance, partnership, and FAQ components.
- src/components/discovery: local idea brief form and downloadable text summary.
- src/components/layout: shared navigation, footer, and page shell.
- src/components/primitives: reusable buttons, sections, containers, cards, badges.
- src/components/seo: safe JSON-LD rendering.
- src/content: typed bilingual copy and configurable product data.
- src/i18n: locale routing and direction.
- src/lib/seo.ts: canonical, alternate-language, social, and structured metadata.
- src/styles: shared tokens, typography, atmosphere, and reduced-motion rules.
- messages: shared navigation and accessibility translations.
- scripts/audit-story.mjs: repeatable browser and production-route verification.

The homepage order is defined in Landing.tsx. Update narrative.ts for journey,
working models, FAQs, and brief labels; landing.ts for hero and compact agent
copy. Industry previews reuse industries.ts instead of duplicating workflows.
Static storytelling is rendered on the server. Only the demonstrations and form
are client components. Both languages share the same components.

## SEO and machine-readable content

siteConfig.url is https://okai.sa. Each content route has a unique canonical and
Arabic/English alternates. The homepage includes Organization, WebSite, WebPage,
Service, and FAQPage JSON-LD; FAQ answers match visible content. robots.txt and
sitemap.xml are generated by Next.js. public/llms.txt provides a factual site
summary with qualifications and links. This does not guarantee AI citations,
indexing, rankings, or rich results. Social previews are generated locally.

Sign-in is an existing placeholder, excluded from the sitemap and marked noindex.

## Demonstration boundaries

The journey and integration interfaces are clearly labeled examples. They do
not call business systems. The discovery form runs locally, keeps answers in
memory, and downloads a text brief. It does not send leads, book a meeting, or
contact an AI model. A live discovery service needs a backend, model connection,
privacy review, and booking/contact destination before those actions are enabled.

Partnership copy describes a proposed working model subject to assessment and
agreement. No invented pricing, customer results, certifications, or guaranteed
success are included. Becoming a business incubator is a stated vision.

## Visual verification

Start a dedicated headless Chrome instance with remote debugging on port 9223
and the production app on 3001. Then run:

```sh
node scripts/audit-story.mjs
```

The audit checks both languages at 320, 375, 768, 1024, and 1440px; six journey
stages; three workflows; reduced motion; idea brief submission; page responses;
canonical links; JSON-LD; sitemap; robots; and social image output.
Screenshots and results are written to ignored artifacts/story-audit.
